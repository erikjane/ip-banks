# ip-banks — отчётность 15 банков РФ для частного инвестора

Каждый день GitHub Actions скачивает с сайта Банка России формы 0409101, 0409102, 0409123 и 0409135,
считает метрики и светофор и кладёт результат в `data/`. Google Таблица «Банки РСБУ» подтягивает
`data/summary_ru.tsv` и `data/monthly_ru.tsv` через IMPORTDATA.

| Файл | Что внутри |
|---|---|
| `data/summary.csv` | последний месяц по каждому банку: метрики, изменения год к году, сигналы, вердикт |
| `data/monthly.csv` | все метрики по месяцам с июля 2023 года |
| `*_ru.tsv` | те же данные с десятичной запятой для русской Google Таблицы |
| `data/debug/` | свёрнутые группы счетов формы 101, справочник кодов 102 |

Банки и регномера: Сбербанк 1481, ВТБ 1000, Альфа-Банк 1326, Т-Банк 2673, Газпромбанк 354, ВБ Банк 841,
Совкомбанк 963, ДОМ.РФ 2312, Россельхозбанк 3349, Озон Банк 3542, Банк Санкт-Петербург 436, МКБ 1978,
Точка 3545, Яндекс Банк 3027, МТС-Банк 2268.

**Методика (форма 101, счета первого порядка):**
- прибыль — счёт 706 (пассив − актив); сверено с формой 102 (61101 − 61102) — совпадает у всех банков;
- кредиты юрлицам — 441–454, 456 и свёрнутые группы 44.x/45.x (кроме 45.2); физлицам — 455, 457, группа 45.2;
- просрочка — 458 + 459 (актив); резервы — пассивные части кредитных счетов, 458 и 459;
- вклады населения — 423, 426, группа 42.2; средства юрлиц — 405–407, 410–422, 425, группа 42.1; текущие счета — 408;
- капитал для ROE — 102, 106, 107, 108, 706–708 минус 105, 106 (актив), 109; ROE = прибыль за 12 мес ÷ средний капитал за 12 мес;
- H1.0 — форма 135.

Пороги светофора — в `scripts/signals.py` (переменная `TH`).
Это РСБУ самого банка, без дочерних компаний. Не является индивидуальной инвестиционной рекомендацией.
