# Сайт «Инвест Привет+»: Инвест-часы и отрасли

Сайт лежит в папке `docs/` и раздаётся через GitHub Pages. Данные — готовые JSON в `docs/data/`.
Их раз в 15 минут собирает workflow `site-data` (`.github/workflows/site.yml`) скриптом `site/build_data.py`.
Посетители к Google не обращаются: за прогон уходит по одному запросу на таблицу.

| На сайте | Источник | Файл |
|---|---|---|
| Инвест-часы | Google-таблица «Инвест-часы: тест фазы цикла», лист «Тест» (публикуется только с галочкой ОК) | `docs/data/clock.json` |
| Тест для посетителей | вопросы теста | `docs/data/test.json` |
| Отрасли → Банковский сектор | Google-таблица «Банковский сектор» | `docs/data/sectors/banks.json` |
| Ежемесячное РСБУ | `data/summary.csv`, `data/monthly.csv` этого репозитория | `docs/data/rsbu.json` |
| Металлурги (пока неактивны) | Google-таблица «New Металлуги» | `docs/data/sectors/metals.json` |

Список отраслей и ID таблиц — `site/config.json`. Новая отрасль: добавить `spreadsheet_id`, когда раздел готов — `"active": true`.
Если таблица недоступна, сборка оставляет прежние данные и пишет предупреждение в лог.

## Настройка (один раз)

1. **Сервисный аккаунт Google.** console.cloud.google.com → создать проект → «APIs & Services» → Library → включить **Google Sheets API**.
   Затем IAM & Admin → Service Accounts → Create service account (любое имя, роли не нужны) → открыть его → Keys → Add key → JSON. Скачается файл-ключ.
2. **Доступ к таблицам.** В каждой из трёх таблиц: «Настройки доступа» → добавить email сервисного аккаунта (`...@...iam.gserviceaccount.com`) как **Читатель**.
3. **Секрет.** GitHub → ip-banks → Settings → Secrets and variables → Actions → New repository secret: имя `GOOGLE_SERVICE_ACCOUNT_JSON`, значение — всё содержимое JSON-ключа.
4. **Pages.** Settings → Pages → Source: Deploy from a branch → `main` / `/docs` → Save. Сайт: `https://erikjane.github.io/ip-banks/`. Свой домен (поддомен investprivet.online) подключается там же.
5. **Проверка.** Actions → `site-data` → Run workflow.

## Как обновлять часы

Таблица «Инвест-часы», лист «Тест»: ответы A–D, дата, галочка **ОК — публикуем на сайт**. Без галочки на сайте остаются прошлые часы.
Чтобы не ждать 15 минут — меню «Сайт → Опубликовать сейчас» (скрипт `site/publish_now.gs`, настройка внутри файла).

## Как считается время на часах

Каждый ответ — точка в середине своей фазы: A = 7:30 (восстановление), B = 10:30 (пик), C = 1:30 (замедление), D = 4:30 (рецессия).
Стрелка — среднее направление 10 ответов по кругу. Баллы 0–30 из исходного теста считаются и показываются рядом.
